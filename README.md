# To-Do List

A simple and user-friendly To-Do List web application built using **HTML, CSS, and JavaScript**.

## 📌 Project Overview

This project allows users to manage their daily tasks easily. Users can add new tasks, mark tasks as completed, and delete tasks when they are no longer needed.

## 🚀 Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- ❌ Delete tasks
- ⚠️ Prevent adding empty tasks
- 🎨 Simple and clean user interface
- 📱 Responsive layout

## 🛠️ Technologies Used

- **HTML5** – Used to create the structure of the application
- **CSS3** – Used for styling and layout
- **JavaScript** – Used to add functionality and handle tasks
